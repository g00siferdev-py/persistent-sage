# Persistent Sage 2.1.0

**Persistent Sage 2.1.0** is a UX and polish release for both **Companion** and **Coding** modes. It ports quality-of-life improvements from the Snowball line (excluding security-audit tooling) while keeping the Persistent Sage identity and Microsoft Store packaging.

---

## Highlights

### Companion mode

- **Message timestamps** on chat bubbles
- **MessageContent** rendering — improved markdown, code blocks, copy buttons
- **Chat artifacts** styling with light/dark theme support
- **Help menu** — in-app guide with links to docs and privacy policy
- **Token context counter** in the header (estimate for active conversation)
- **Settings panel fixes** — cache manager, appearance, reliable open/close
- **Error boundary** — UI errors show a recoverable message instead of a blank screen
- **Abort turn** — stop an in-progress assistant reply
- **Unified conversation context** — switching Companion ↔ Coding keeps the active thread when linked

### Coding mode

- **Settings in coding** — full settings panel without leaving Coding mode
- **Coding notepad** — scratch notes per repo (agent tool + UI panel)
- **Code playground** — run Python, Node, TypeScript, Bash, PowerShell, or Rust snippets outside the repo
- **Agent Action Stream** — live view of tool calls during agent turns
- **Event Stream Debugger** — inspect raw chat/tool events
- **Resizable side panels** — stream, debugger, and layout persistence
- **Artifacts in coding chat** — same artifact renderer as Companion mode
- **Playground view** — dedicated toolbar mode beside Split / Editor / Chat

### Platform

- **Single-instance guard** — launching again focuses the existing window
- **Cache manager** — view size, open folder, clear temp files under `cache/`
- **Version badge** — header shows `v2.1.0` from the running backend
- **Windows bash playground** — prefers Git Bash over the WSL `bash.exe` shim
