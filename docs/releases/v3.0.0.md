# Persistent Sage 3.0.0

**Persistent Sage 3.0** is a major release: **Moltbook**, **Productivity** mode, Favorites/Share, agent **PDF** tools, **workspace vision**, experimental **subagents**, and chat reliability fixes — on top of Companion + Coding from 2.x.

**Channels:** GitHub tag `v3.0.0` (NSIS + portable + Tauri updater) and Microsoft Store MSIX `3.0.0.0`.

---

## Highlights

### Moltbook

- **Moltbook panel** in Companion chat for feed, search, posting, and commenting
- **Agent tools** — feed/search/post/comment (when enabled in Settings)
- **Scheduler** — background check-in support

### Productivity mode

- Movable **Google Workspace** widgets (Email, Calendar, Drive, Contacts, Tasks)
- Global **Email Agent** thread and `correspondence_sync` for cross-companion context
- Local Weather, Clock, Quick Links, Notepad, and Projects widgets

### Vision & workspace

- Attach images from computer, **webcam**, or **From workspace**
- Agent tool **`workspace_view_image`** for screenshot review (vision-capable models)
- Clearer errors when reading binary images with text-only `workspace_read_file`

### Chat UX

- **Favorites** and **Share** / copy actions
- Fenced **code blocks** render with highlighting and copy
- Companion replies no longer “ghost” after heavy workspace tool turns
- Webcam capture; token counter; abort turn

### Agent tools & Settings

- PDF read/create in the workspace
- **Subagents (experimental)** — nested workers use more tokens
- Settings tabs: General / Provider / Tools
- OpenRouter and other providers in Settings → Provider

### Platform & updates

- **Settings → General → Updates** works for both install sources:
  - **Microsoft Store** → Store package APIs
  - **GitHub** (NSIS / portable) → signed Tauri updater (`latest.json` on Releases)
- Version badge shows `v3.0.0`

## Upgrade notes

- Existing data, personalities, and repos are preserved.
- Enable **workspace tools** for PDF and `workspace_view_image`; enable **Moltbook** for social tools.
- Screenshot review needs a **vision-capable** model (e.g. gpt-4o, Claude 3+, kimi, llava).
- Subagents are experimental and increase token usage.
- PDF creation requires Chrome, Chromium, or Edge (same as `fetch_browser`).
