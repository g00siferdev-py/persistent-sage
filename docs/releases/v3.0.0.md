# Persistent Sage 3.0.0

**Persistent Sage 3.0** is a major feature release for Companion mode: **Moltbook**, Favorites, Share/copy enhancements, agent **PDF** tools, personality update improvements, webcam capture, and a clearer Settings layout — on top of the Companion + Coding foundation from 2.x.

This build is offered as a **beta** for testers (`v3.0.0-beta.1`). The official **Microsoft Store** version is planned for **August 3**.

---

## Highlights

### Moltbook

- **Moltbook panel** in Companion chat for feed, search, posting, and commenting
- **Agent tools** — `moltbook_feed`, `moltbook_search`, `moltbook_create_post`, `moltbook_comment` (when enabled in Settings)
- **Scheduler** — background check-in / scheduling support
- **Verification** — backend support for Moltbook account verification flows

### Personality

- Improved **personality file update** and import flow in Settings
- Prompt wiring stays aligned when companion personality content changes

### Agent PDF tools

- **`workspace_read_pdf`** — extract text from workspace PDFs
- **`workspace_write_pdf`** — create PDFs from Markdown, HTML, or plain text; convert existing `.md` / `.html` / `.txt` via `source_path`
- Renders through the same headless Chrome / Chromium / Edge path used by `fetch_browser`

### Chat UX

- **Favorites** panel — pin and revisit favorites
- **Share menu** and enhanced **copy / message actions**
- **Webcam capture** for chat image attachments

### Settings & coding polish

- Settings split into **General**, **Provider**, and **Tools** tabs
- Markdown / JSON playground panels and syntax highlighting improvements
- Ollama tool calling no longer stuck disabled after image messages

### Platform

- **Version badge** — header shows `v3.0.0` from the running backend
- GitHub Windows NSIS + portable installers via CI on tag push

## Upgrade notes

- Existing data, personalities, and repos are preserved.
- Enable **workspace tools** for PDF read/create; enable **Moltbook** settings for social tools.
- PDF creation requires a system Chrome, Chromium, or Edge binary (same as `fetch_browser`).
- Beta testers: install from the `v3.0.0-beta.1` GitHub Release (NSIS or portable). Expect iterative fixes before Store launch.
